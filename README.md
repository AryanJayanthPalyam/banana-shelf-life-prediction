# Banana Shelf Life Prediction

A machine learning project to predict the shelf life of bananas based on environmental and physical factors.

---

## 🚀 Features
- Data preprocessing and cleaning  
- Feature engineering for ripeness indicators  
- Machine learning models for prediction  
- Evaluation metrics for accuracy and reliability  
- Visualization of results  

---

## 🛠️ Tech Stack
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib, Seaborn  

---

## 📋 Prerequisites
- Python 3.8+  
- Required libraries in `requirements.txt`  

---

## 🚀 Quick Start

```bash
# Clone the Repository
git clone https://github.com/AryanJayanthPalyam/banana-shelf-life-prediction.git
cd banana-shelf-life-prediction

# Install Dependencies
pip install -r requirements.txt

# Run Training Script
python train_model.py
